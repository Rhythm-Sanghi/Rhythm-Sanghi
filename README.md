# Rhythm Sanghi

I'm a computer science student in India. I build desktop tools and web apps, especially projects that make it easier to see what happened and why.

## Selected work

| Project | What you can try |
| --- | --- |
| [AccessMaze](https://github.com/Rhythm-Sanghi/AccessMaze) | Replay a website task with keyboard-only input and inspect where it gets stuck. |
| [HearGlass](https://github.com/Rhythm-Sanghi/HearGlass) | Add a caption overlay to the audio already playing on a Windows PC. |
| [Threadmark](https://github.com/Rhythm-Sanghi/Threadmark) | Follow a dependency from a symbol to its callers and inspect the source behind each connection. |
| [Benchlight](https://github.com/Rhythm-Sanghi/Benchlight) | See where development tools and projects take up space and compare saved snapshots. |
| [TakeTwo](https://github.com/Rhythm-Sanghi/TakeTwo) | Compare two recordings of the same passage and listen to the difference at the part that changed. |
| [BhumiSetu](https://github.com/Rhythm-Sanghi/bhumisetu-indore) | Load the Indore reference maps and review where geometries or attributes disagree. |
